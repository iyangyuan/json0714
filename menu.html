Menu ​

The main entry points for using json0714 are only two: the context menu and keyboard shortcuts.
The design philosophy of json0714 is not to over-intervene in or intercept the browser's network requests, but only to be actively invoked when you need it.
json0714 can run on any page except the New Tab page.

Standard context menu ​

Right-click anywhere in the browser to see the json0714 menu.
You can use the shortcuts shown in the menu to quickly access the corresponding functions without relying on mouse operations; I use keyboard shortcuts most of the time.

Format current page JSON ​

Use the content displayed on the current page as JSON input.

Format JSON from clipboard ​

Use the content in the clipboard as JSON input.

Copy JSON ​

Copy the formatted JSON in the current workspace.
The copy and paste functions greatly simplify the interaction flow between users and the extension, acting as a highway for improving efficiency.

Quick view ​

In Quick view mode, each [] list node retains at most 3 data entries, making it easier to analyze extremely large JSON structures.

Lock ​

  • Lock current path: Exactly match the current page URL; afterward, when the browser visits that URL, the extension runs automatically.
  • Lock current domain: Match the current page domain; afterward, when the browser visits that domain, the extension runs automatically.
  • Unlock: Cancel the automatic running effect of the extension for the current URL or current domain.

Key sorting ​

When formatting, automatically sort JSON keys in ASCII lexicographical order.
When None is selected, preserve the original input order.

More settings ​

Open the settings page; see the Settings chapter for details.

Selection context menu ​

Right-click on selected text, and the menu will show json0714's context menu.
This capability is not limited to the json0714 workspace; it can be used on any webpage opened in Chrome.

Generate QR code ​

Generate a QR code corresponding to the selected text and display it in a popup.
It is a bridge for transferring data from desktop to mobile.
The extension itself does not limit or validate the length of the selected text; it is recommended to keep it within 200 characters, as overly long text may cause an error.

Date/time formatting ​

Try to convert the selected text into the standard time format yyyy-MM-dd HH:mm:ss for easier reading, and display it in a popup.
The extension itself does not impose restrictions or validation on the selected text, supports multiple time formats, and gives a prompt when it fails.
If there is an unsupported time format, you are welcome to submit a request on GitHub.

Copy selection screenshot ​

Use the currently selected text area as the boundary to take a cross-screen screenshot within the browser. Compared with a long screenshot of the entire page, the granularity is finer, the purpose is more targeted, and it saves more resources.
Due to hard browser policy restrictions, the extension cannot access content in iframes, so screenshots targeting iframes will fail; in this case, it is recommended to use the Open frame in new tab feature provided by this extension. Open the embedded iframe in a new tab, and the iframe will naturally become a regular page, with no screenshot restrictions in the new tab.

Visit selected link ​

Try to open the selected text as a link in a new tab.
The extension itself does not impose restrictions or validation on the selected text.

Download selected link ​

Try to download the selected text as a download link.
The extension itself does not impose restrictions or validation on the selected text.

Iframe context menu ​

Right-click within an iframe, and the menu will show json0714's iframe menu.

Open frame in new tab ​

Open the embedded iframe in a new tab.
