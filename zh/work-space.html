工作空间 ​

json0714 的格式化结果展示页面。
此处加载的所有内容均由插件生成，原始网页已被覆盖，无法还原。
默认情况下，json0714 接受任何输入；如果输入内容不是 JSON，则会将其转换为 ["原始输入"] 模式进行格式化并展示。这一设计使 json0714 能够容纳任意内容，并与右键上下文菜单功能无缝对接，释放出更大潜力。

功能清单 ​

  • 支持 JSONP
  • 显示行号；点击行号可添加行标记，用于标记重要位置
  • 括号配对高亮
  • 点击可快速选中整个字符串，拖动可选择部分字符串
  • 相同字符串提示
  • 严格保留原始字面量
  • 左上角实时显示当前视区顶部所在的 JSON Path，点击可快速跳转定位
  • 点击值时，左下角状态栏显示该值的 JSON Path，可选中复制
  • 右上角提供小地图预览，拖动可快速滚动
  • 右下角提供折叠按钮，可启用折叠功能
  • 鼠标悬停在 [ 上时显示数组长度；悬停在 { 上时显示对象 key 数量
  • 底部状态栏显示：当前选中字符数量、原始输入 JSON 字符串大小、JSON 最大层级深度、原始输入 JSON 字符串的 CRC32 校验值
