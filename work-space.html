Workspace ​

The page where json0714 displays formatting results.
All content loaded here is generated by the extension; the original webpage has been overwritten and cannot be restored.
By default, json0714 accepts any input; if the input is not JSON, it will be converted into the ["raw input"] mode for formatting and display. This design allows json0714 to accommodate arbitrary content and seamlessly integrate with the context menu features, unlocking greater potential.

Feature list ​

  • Supports JSONP
  • Displays line numbers; click a line number to add a line marker for marking important positions
  • Bracket pair highlighting
  • Click to quickly select the entire string; drag to select part of the string
  • Hints for identical strings
  • Strictly preserves original literals
  • Displays in real time at the top left the JSON Path of the top of the current viewport; click to quickly jump and locate
  • When clicking a value, the status bar at the bottom left displays the JSON Path of that value, which can be selected and copied
  • Provides a minimap preview at the top right; drag to quickly scroll
  • Provides a collapse button at the bottom right to enable the collapse feature
  • Hovering over [ shows the array length; hovering over { shows the number of object keys
  • The bottom status bar displays: the number of currently selected characters, the size of the original input JSON string, the maximum JSON nesting depth, and the CRC32 checksum of the original input JSON string
